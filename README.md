# Kopi Tuku — Marketing Campaign Performance Analysis

## Overview

This project presents an interactive dashboard for analyzing the marketing and business performance of Kopi Tuku.

The dashboard was developed using **Looker Studio** to transform campaign performance data into interactive visualizations and key performance indicators (KPIs).

## Dashboard

The dashboard provides an overview of:

- Total Transactions
- Net Revenue
- Total Profit
- Profit Margin
- Average Order Value (AOV)
- ROAS
- Customer Segment performance
- Net Revenue trends by Marketing Channel
- Campaign Type performance
- Net Revenue by City
- Profit by Marketing Channel
- Product performance

The dashboard also includes interactive filters for:

- Transaction Date
- Marketing Channel

## Problem

Kopi Tuku campaign performance data contains multiple business dimensions, including transactions, revenue, profit, customer segments, campaign types, marketing channels, products, advertising spend, and ROAS. Without an integrated visualization, it can be difficult to identify performance patterns and compare different campaign and marketing dimensions efficiently.

## Action

The data was prepared and visualized in Looker Studio by creating an interactive business intelligence dashboard.

The dashboard combines KPI scorecards, charts, a performance table, a geographic visualization, and interactive filters to support exploration of campaign performance.

## Result

The resulting dashboard provides a centralized view of Kopi Tuku's campaign performance and makes it easier to compare revenue, profitability, customer segments, campaign types, products, cities, and marketing channels.

The dashboard can be used as a visual analytical tool to support data-driven understanding of marketing and business performance.
